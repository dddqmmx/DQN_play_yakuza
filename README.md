# DQN_play_yakuza

Yakuza 6 reinforcement-learning control experiment using DQN-style agents.

See [DISTRIBUTED.md](D:/DQN/DISTRIBUTED.md) for the two-node AI/game runtime.

## Dependencies

Game machine:

```bash
pip install -r requirements-game.txt
```

AI/training machine:

```bash
pip install -r requirements-ai.txt
```

For CUDA-specific PyTorch builds, install PyTorch from the official selector before installing the AI requirements.
